Audience: whoever copies this overlay into their own deck.

This folder is a Slidev deck. Copy `global-bottom.vue` and
`components/CoPresenter.vue` next to your `slides.md`. The overlay talks to
the co-presenter service at `http://127.0.0.1:3040`, or to the address in the
`copresenter` query parameter. How to run the service is
[`copresenter/README.md`](../../copresenter/README.md).
